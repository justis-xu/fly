# fly

轻量本地代理切换器：单个二进制文件，内嵌 [mihomo](https://github.com/MetaCubeX/mihomo) 内核与 Web 控制台。不设系统代理、无 TUN、无网络扩展，浏览器代理插件指向本地端口即用。

## 安装

需要 Go ≥ 1.20（开发环境为 1.26）：

```sh
make install
```

自动装到 `/opt/homebrew/bin/fly`（存在且可写时），否则装到 `~/go/bin`（需自行加入 PATH）。卸载：`make uninstall`。

## 使用说明

### 首次使用

```sh
fly          # 1. 后台启动（首次自动生成 ~/.fly/fly.yaml，订阅地址默认已内置）
fly ui       # 2. 打开控制台 http://127.0.0.1:7889
```

3. 浏览器代理插件（Proxy Switcher 等）把 HTTP/SOCKS 代理指向 **127.0.0.1:7888**，完成。

### 日常操作（都在控制台页面上）

- **切换节点**：管理页点击节点即切换，顶部显示当前节点；节点延迟自动测出（绿 <300ms / 黄 <1000ms / 红 / 灰=超时）
- **一键测速**：页面打开自动测一轮，也可手动点「⚡ 一键测速」挑可用节点
- **更新订阅**：点「↻ 更新订阅」重新拉取节点，当前选择保持不变
- **换订阅地址**：点「⚙ 订阅设置」，粘贴新地址保存，立即拉取生效
- **完整面板**：点「▦ 完整面板」进入 metacubexd（实时流量图、活动连接、规则命中、日志、运行模式切换）

### 命令行

| 命令 | 说明 |
|---|---|
| `fly` / `fly start` | 后台启动；已运行则提示 |
| `fly stop` | 停止 |
| `fly restart` | 重启 |
| `fly status` | 状态、当前节点、最快节点、流量、到期 |
| `fly ui` | 打开控制台 |
| `fly update` | 立即刷新订阅（热重载，选择不丢） |
| `fly run` | 前台运行（调试用，Ctrl+C 退出） |
| `fly init --url <地址> --port <端口>` | 命令行方式查看/修改配置 |

换订阅地址也可以：`fly init --url https://... && fly restart`

### 控制台地址

| 地址 | 用途 |
|---|---|
| `http://127.0.0.1:7889` | fly 管理页（切节点 / 测速 / 订阅管理） |
| `http://127.0.0.1:7889/panel/` | metacubexd 完整面板 |

## 端口与数据

| 端口（全部只绑 127.0.0.1） | 用途 |
|---|---|
| 7888 | 本地混合代理（HTTP/SOCKS，浏览器插件指向它） |
| 7889 | Web 控制台 |
| 9090 | mihomo 控制接口（控制台内部使用） |

数据目录 `~/.fly/`：`fly.yaml`（配置）、`sub-cache.txt`（订阅缓存）、`cache.db`（节点选择持久化，重启不丢）、`fly.log`（日志）、`fly.pid`。

## 工作原理

单进程 Go 程序，把 mihomo 作为库嵌入：拉取订阅 → 解析节点（base64 分享链接或 Clash YAML 均可，自动过滤机场流量信息占位节点）→ 生成 mihomo 配置 → 启动本地代理。订阅提供 Clash 配置时直接采用其分流规则（组名自动改写到 `🚀 Proxy`）；否则使用内置规则（国内直连、国外走代理）。geo 数据内嵌二进制，运行期零外部下载。订阅每 24 小时自动刷新；拉取失败自动用上次缓存启动。

## 常见问题

- **`fly status` 显示「正在启动加载」**：订阅源响应慢（本订阅域名偶尔 TTFB 超过 10 秒），等 1-2 分钟再查即可
- **status 显示「缓存模式」**：最近一次拉取失败（网络波动），当前用的是上次成功的节点列表，代理不受影响；网络恢复后点「更新订阅」或等自动刷新
- **控制台打不开**：确认 `fly status` 为运行中；若端口被占用，查看 `~/.fly/fly.log`

## 说明与边界

- 本工具不修改系统代理、不创建虚拟网卡，流量出口由你自己在浏览器插件里指定
- 无法保证对抗所有终端检测手段（如流量侧深度包检测不在其能力范围）
- 仅供个人在自有设备上合规使用，请遵守所在环境的规定
