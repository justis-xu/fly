# 配合 Proxy Switcher 使用

fly 只提供本机代理服务器。**Proxy Switcher** 决定浏览器哪些请求交给 fly；fly 决定这些请求按规则直连还是走你自己的订阅节点。没有订阅节点时，fly 不提供可直接使用的代理出口。

## 一次配置

1. 运行 `fly start`，再运行 `fly ui` 打开 [管理网页](http://127.0.0.1:7889)。
2. 在网页「修改订阅地址」中填写自己的 HTTP / HTTPS 订阅地址，点击「保存并更新」。
3. 等待节点出现，确认规则集已加载。点击节点即可选中，也可使用「自动选择」。
4. 从浏览器扩展商店安装你使用的 **Proxy Switcher**。在插件中新增一个代理配置，名称可填 `fly`，协议选 HTTP，主机填 `127.0.0.1`，端口填 `7888`，无须代理用户名或密码。
5. 需要代理的 HTTP 和 HTTPS 网站均使用这个 HTTP 代理配置。HTTPS 请求会通过 CONNECT 隧道发送，不要把协议误设成需要 TLS 连接本地服务器的「HTTPS 代理」。
6. 在 Proxy Switcher 中启用刚保存的配置。插件若按网站分流，只有其选中走代理的网站才会到达 fly；未选中的请求由浏览器直接处理。

插件界面因版本不同会有差异，填写的协议、主机、端口保持上述值。也可选 SOCKS5，使用相同地址；若支持远程 DNS，建议同时启用。无需同时配置两种协议。

## 日常使用

- **启动 / 停止**：`fly start` / `fly stop`。停止前先在 Proxy Switcher 中切回直连，避免插件继续向已停止的服务器发送请求。
- **选节点**：`fly ui` 打开网页，点击节点，顶部立即显示当前选择。测速用于比较连通性和延迟，不代表完整带宽。
- **自动选择**：fly 定期检查节点，使用延迟较低的可用节点。初次启动时可手动点击「测速」。
- **更新**：网页点击「更新订阅」，或执行 `fly update`。页面完成提示和 `fly status` 可查看更新结果。
- **换订阅**：展开「修改订阅地址」，保存后自动加载。若更新失败，检查警告；正在使用的仍可能是上次缓存中的节点。
- **看规则**：展开「查看规则详情」。订阅策略统一映射到所选节点，DIRECT / REJECT 等内置策略保留，不需要另选模式或管理一堆策略组。

## 端口与配置

| 默认地址 | 填在哪里 |
|---|---|
| `127.0.0.1:7888` | Proxy Switcher 的主机与端口 |
| `http://127.0.0.1:7889` | 浏览器地址栏，用于管理 fly |

修改代理端口后，例如 `fly init --port 7898`，执行 `fly restart`，同时把 Proxy Switcher 中端口改成 `7898`。管理地址以 `fly status` 为准。所有监听地址仅供本机使用。

数据目录 `~/.fly/`：`fly.yaml` 为启动配置，`sub-cache.txt` 和 `sub-meta.json` 为订阅缓存，`cache.db` 保存节点选择，`rules/` 保存规则资源，`fly.log` 为日志，`fly.pid` 为后台进程记录。配置与缓存可能包含订阅凭据，不要公开分享。
