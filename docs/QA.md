# 检查清单与验证记录

本页记录可重复的检查步骤，区分代码测试、演示页面测试和实际浏览器代理操作。普通用户遇到问题先看[常见问题](FAQ.md)。

## 用户首次使用检查表

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 安装 | 按 INSTALL 执行 `make install`，再 `fly version` | 路径可找到，输出版本 |
| 启动 | `fly start`，再 `fly ui` | 唯一 fly 网页，首次提示添加订阅 |
| 添加订阅 | 粘贴自己的链接，保存并更新 | 节点列表出现，显示服务运行中 |
| 插件安装 | 打开指定 Chrome 商店链接，核对名称和 ID | 安装的是 Proxy Switcher and Manager |
| 固定图标 | 拼图菜单 → 对应行图钉 | 地址栏旁可打开插件 |
| 配置 | Manual Proxy，fly，HTTP/SSL=127.0.0.1:7888，类型 HTTP | 绿色 ✓ 保存应用，重开仍保留 |
| 选节点 | fly 页面点击另一个节点 | 顶部当前使用和选中样式同步 |
| 使用 | Chrome 新开 / 刷新目标网页 | 页面正常加载；规则可能选择直连或节点 |
| 停止 | 插件 Direct，再 `fly stop` | Chrome 不依赖已停止的 fly |
| 再启动 | `fly start`，插件 Manual Proxy | 可复用保存的订阅与插件配置 |

## 开发回归检查

### 自动检查

```sh
cd web
npm ci --no-fund --no-audit
npm test
npm run build
npm run typecheck
cd ..
go test -race ./...
go vet ./...
go build -o fly .
git diff --check
```

构建检查还覆盖 React 流式数据分块的等价性，以及真实页面 / 数据改动的识别。

前端交互覆盖：首次添加订阅、URL 校验、搜索、切换失败、更新失败、复制代理地址、输入遮挡、离线状态、订阅读取失败保护、StrictMode 请求取消、慢后台刷新时的操作结果，以及错误文本 URL 脱敏。

Go 检查覆盖订阅 / 缓存 / 规则 / 就绪与本机管理限制；新增检查会从实际 HTML 解析静态资源，确认 JS/CSS 正确提供、缺失资源返回 404。

### 实际页面

使用不含个人凭据的演示 API 拍图，分别检查：

- 空订阅页面、添加弹窗、保存后页面。
- 节点搜索、选中、测速、自动选择。
- 更新和修改订阅、读取失败、服务断开。
- 分流规则展开和规则集实际数量。
- 桌面与 390px 窄屏布局、弹窗滚动、键盘可操作性。
- 控制台无 hydration 错误，JS/CSS 请求无 404。

演示服务见[开发说明](DEVELOPMENT.md)。它不能证明真实节点可连通。

### 实际代理连接

先运行 fly、等订阅就绪。开发者可在终端分别检查：

```sh
curl --noproxy '' --proxy http://127.0.0.1:7888 --max-time 20 -o /dev/null -w '%{http_code}\n' https://www.gstatic.com/generate_204
curl --noproxy '' --socks5-hostname 127.0.0.1:7888 --max-time 20 -o /dev/null -w '%{http_code}\n' https://www.gstatic.com/generate_204
```

测试地址预期返回 `204`。这些是 HTTP / SOCKS5 协议检查，**不能代替插件操作验收**。网站、订阅和网络改变时，结果也可能改变。

再按 [PROXY_SWITCHER.md](PROXY_SWITCHER.md) 在 Chrome 实际插件面板保存并启用，打开目标网页，并切 Direct 恢复。插件查询 IP 的结果受分流规则影响，不能单凭 IP 相同认定失败。
