# QA 检查清单与验证记录

fly 是搭配 **Proxy Switcher** 使用的本地代理服务器；不提供订阅或节点，也不自动接管浏览器流量。服务器协议测试和插件实际操作是两项独立验收，不能相互替代。

## 开发检查

在项目目录执行：

```sh
go test -race ./...
go vet ./...
go build -o fly .
git diff --check
```

当前有 19 个测试函数，覆盖：

- 空订阅的新安装状态、非法端口 / 非本机管理地址 / 错误刷新间隔。
- 订阅 RULE-SET 与资源保留，直连和 PASS-RULE 策略、多重修饰符、子规则未匹配时继续后续规则。
- 不可用节点不阻塞规则直接下载，规则 URL 改变后不复用旧源缓存，ASN 数据可用。
- 更新失败保留运行状态与缓存，冷启动遇到无效配置时回退可用缓存。
- 保存失败不改原地址，更新期间拒绝重入，拒绝外站 Origin 和非本机 Host。
- 首次安装管理网页仍可访问，管理端口及代理 TCP / UDP 端口冲突不误报就绪。

安装 / 卸载可用临时目录验证，避免影响正在使用的程序：

```sh
make install DEST=/tmp/fly-install-check
/tmp/fly-install-check/fly version
make uninstall DEST=/tmp/fly-install-check
```

## 服务器与管理网页验收

1. `make install`，`fly restart`，`fly status`；核对 Proxy Switcher 代理地址与管理网页地址。
2. 首次安装应没有内置订阅，可打开网页填写自己的地址；已有配置升级后应保留。
3. 网页切换节点并核对顶部；更新、重启后选择应保留。打开搜索、测速、订阅修改及规则详情，确认错误可见。
4. 默认只监听本机 `7888` 和 `7889`，没有单独控制端口；旧 `/panel/` 应回到同一页面。
5. 规则集应显示实际条目数；空集或下载失败不可声称全部生效。
6. 使用 HTTP 和 SOCKS5 连接本地服务器，确认可转发 HTTPS 请求。例如：

```sh
curl --noproxy '' -x http://127.0.0.1:7888 \
  --max-time 15 -o /dev/null -w '%{http_code}\n' \
  https://www.gstatic.com/generate_204
curl --noproxy '' --socks5-hostname 127.0.0.1:7888 \
  --max-time 15 -o /dev/null -w '%{http_code}\n' \
  https://www.gstatic.com/generate_204
```

这两条命令仅用于测试本地服务器，日常浏览器仍使用 **Proxy Switcher**。

## Proxy Switcher 真实插件验收

需在安装了该插件的用户浏览器中操作：

- [ ] fly 服务和订阅均已就绪。
- [ ] 插件 HTTP 代理配置填写 `127.0.0.1:7888`，启用后可打开 HTTPS 网站；或选择 SOCKS5，使用相同地址。
- [ ] 确认插件的网站分流规则确实把测试网站交给 fly。
- [ ] fly 网页切换节点后，再访问页面，确认浏览器请求使用新连接。已有长连接可能继续使用旧节点，应重新加载页面或新建连接。
- [ ] fly 停止时，插件仍指向 fly 的请求失败；插件切回直连后浏览器不再依赖 fly。
- [ ] 改动 fly 代理端口时，插件同步修改；不要误用管理网页端口。
