# 常见问题与排查

## fly 和 Proxy Switcher 各做什么？

fly 是本地代理服务器，负责订阅解析、节点选择和请求转发，不提供代理节点或订阅。**Proxy Switcher** 是浏览器入口，负责将浏览器请求发送到 fly。只运行 fly 不会自动改变浏览器、系统或其他软件的网络路径。

## 为什么启动了 fly，浏览器还是没变化？

先在网页添加自己的订阅并等待就绪，再确认 Proxy Switcher 已启用 `127.0.0.1:7888` 的代理配置。如果插件有网站规则，确认当前网站确实被交给 fly。未交给 fly 的请求不会使用 fly 的节点和分流规则。

## 7888、7889、9000、9090 是什么？

默认 `7888` 是 Proxy Switcher 连接的 HTTP / SOCKS5 代理端口；`7889` 是管理网页端口。当前版本不创建 `9000` 或 `9090` 监听，也没有第二套面板。若这些端口仍有监听，检查进程归属，可能是旧进程或其他软件。自定义端口以 `fly status` 为准。

## HTTPS 网站该如何配置？

在 Proxy Switcher 使用 **HTTP 代理** `127.0.0.1:7888`，HTTPS 网站通过 CONNECT 隧道访问。也可使用 SOCKS5。这里的 HTTP 指本地代理连接协议，不表示只能打开 HTTP 网站。

## 首次启动没有节点，怎么办？

fly 不内置订阅。运行 `fly ui`，在网页填入自己的订阅。没有订阅或首次订阅失败时，管理网页仍可使用；代理端口在成功加载前不会就绪。默认支持有节点的 Clash YAML、明文或 base64 分享链接订阅，暂不支持只有 `proxy-providers` 而没有节点列表的配置。

## 更新失败会不会把原来的节点弄没？

失败更新保留可用配置和缓存。冷启动时也会尝试回退上次可用缓存，并显示警告。配置的新地址不等于已经成功载入新订阅，需确认网页警告和更新时间。没有任何可用缓存时，请在网页修改订阅或检查网络。

## 规则为什么显示「尚未就绪」？

该规则集内容为空，或资源没有下载成功。HTTP 规则资源由 fly 直接下载，不依赖所选节点。检查网络及 `~/.fly/fly.log`，稍后更新订阅。基础 GeoIP、GeoSite、ASN 数据已内置，但机场提供的规则集本身仍需下载。直连访问不了规则资源时，它可能继续未就绪；页面显示已就绪的其他规则不代表这部分规则完整生效。

## 某个节点超时怎么办？

点击「测速」，选择可用节点或「自动选择」。测试延迟只是该时刻的连通性，不保证所有网站可达。也要确认订阅未到期、额度未用完，以及 Proxy Switcher 的地址没有填成 `7889`。

## 管理网页打不开或端口被占用？

运行 `fly status`。未运行则 `fly start`；运行异常时查看 `~/.fly/fly.log`。管理端口被占用会阻止启动；代理端口被占用会显示未就绪，需要先处理冲突再重启。不要直接停止不明进程。

## 停止或卸载后，浏览器不能上网？

在 **Proxy Switcher** 中切回直连。插件若仍指向已停止的 fly，请求就会失败。fly 不会替你修改插件配置。

## 能否保证公司安全软件发现不了？

不能。本地进程、监听端口和网络请求仍可能被识别。fly 不修改系统代理、不启用 TUN，也不提供隐藏或规避检测功能。

## 卸载会删除订阅吗？

`make uninstall` 只删除安装的程序，不删除 `~/.fly/`。停止服务器并在 Proxy Switcher 切回直连后卸载。配置含有凭据，请妥善保管。
