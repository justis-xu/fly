# fly Next.js UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. User authorized inline execution and final commit/push.

**Goal:** 用 Next.js/React 重建简单蓝白单页面，并交付 GitHub 图文入门手册。

**Architecture:** web/ 保存 TypeScript App Router 源码与 shadcn/ui 组件；静态导出到 internal/server/ui，由现有 Go HTTP 服务内嵌提供。既有 API 和两个本机端口保持，手册图片使用仓库相对路径。

**Tech Stack:** Next.js、React、TypeScript、Tailwind CSS、shadcn/ui；Go/mihomo。

**Spec:** docs/superpowers/specs/2026-10-25-next-ui-design.md

## Global Constraints

- 默认代理端口 7888，管理端口 7889；无 Next 运行服务。
- fly 不内置订阅或节点；浏览器必须通过 Proxy Switcher 接入。
- 蓝白风格、单管理页面、系统字体；订阅凭据不进入发布资源或截图。
- 已构建静态文件随仓库提交，使普通 Go 安装不依赖 Node；修改前端后统一重建。
